# Portfolio de Bahidj Saka

Portfolio personnel présentant des projets de marketing, de communication, de jeu vidéo et d'événementiel.

Le site est statique : ouvrir `index.html` pour un aperçu ou utiliser GitHub Pages. Les fiches distinguent les travaux académiques des expériences professionnelles et donnent accès aux présentations collectives disponibles.

Les documents de projets restent la propriété de leurs auteurs et contributeurs respectifs.
